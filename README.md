# 🚀 Portfólio Pessoal | Bruno Bernardes

Um portfólio web moderno, responsivo e interativo desenvolvido com foco em performance, acessibilidade e design elegante no estilo *Glassmorphism*.

---

## 📌 Sobre o Projeto

Este projeto consiste na minha página pessoal para exibição de habilidades, formação e projetos desenvolvidos na área de desenvolvimento Web e Mobile. 

A interface conta com:
- **Design Glassmorphism:** Efeitos de transparência, desfoque (*backdrop-blur*) e iluminação ambiente.
- **Alternância de Tema (Dark/Light Mode):** Suporte nativo a temas claro e escuro com persistência via CSS.
- **Filtro de Categorias Dinâmico:** Navegação rápida pelos cards com animações suaves de entrada (*fade-in*).
- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do projeto.
- **CSS3:** Flexbox, CSS Grid, variáveis nativas, efeitos de vidro e keyframes para animações.
- **JavaScript (ES6+):** Manipulação de DOM para filtragem dinâmica e alternância de temas.
- **Tabler Icons:** Biblioteca de ícones vetoriais.
